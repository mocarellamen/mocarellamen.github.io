# SubScreen — Беспроводной второй монитор из iPad mini 1 (iOS 9)

Превращает старый iPad (iOS 9.3.5 / 9.3.6) в полноценный сенсорный второй монитор для Windows 10/11 по Wi-Fi (60 FPS, аппаратное декодирование H.264).

## Быстрый старт за 3 шага

1. **Скачайте приложение для Windows:** перейдите в раздел [**Releases**](https://github.com/xabar-aari/xabar-aari.github.io/releases/latest) и скачайте `SubScreen-Windows-v2.2.zip`.
2. **Запустите на ПК:** распакуйте архив и откройте `SubScreen.exe`. Программа автоматически настроит сеть, отключит усыпление Wi-Fi и покажет **6-значный код** (а если у вас один монитор — поможет поставить виртуальный второй экран в один клик).
3. **Установите на iPad и подключитесь:** добавьте в Cydia источник `http://xabar-aari.github.io/`, установите **SubScreen**, введите 6-значный код и нажмите **Подключиться по Wi-Fi**.
